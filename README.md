# Fiona（曌）

面向时空预测研究的论文知识库与问答项目：导入研究论文，围绕问题定义、方法、数据集与实验结论提问，得到有原文依据的回答，并能打开对应页。

中文名“曌”采用本项目的命名意象：日月代表时间，空代表空间；保留英文名 Fiona，与时空数据的研究主题相呼应。

**当前阶段：已有逐页 PDF 解析能力，正在重新确定时空论文语料。下一步先选定首批论文、验证解析质量，再实现带原文页码的切块。检索、问答与网页尚未实现。**

## 已可用的命令

在服务器项目根目录执行；首次安装与解释器检查见[环境搭建教程](1.环境搭建.md)。

```bash
cd /data2/wangjiaji/Fiona
conda activate fiona
python scripts/parse_pdf.py --help
```

复现既有解析样例，并预览关键词所在页面（历史金融样例，仅验证解析能力）：

```bash
python scripts/parse_pdf.py --doc-id cmb_2024_annual --keyword 营业收入
```

解析配置中的全部 PDF：

```bash
python scripts/parse_pdf.py
```

输入文件映射维护在 [configs/pdf_files.json](configs/pdf_files.json)，输入位于 `data/raw/`，输出位于 `data/parsed/<doc_id>.jsonl`。成功重跑会替换同名解析输出。更多参数、退出码、逐页检查及排错见 [PDF 解析教程](docs/development/02-PDF解析.md)。

## 后续开发顺序

以下是工作顺序，版本范围和技术细节统一查[项目开发文档](项目开发文档.md)。

|顺序|交付目标|完成标志|
|---|---|---|
|1|文本切块与知识材料接入|所选论文生成可定位原文的证据块；补齐资料登记、去重、失败重试与持久化，验证 TXT 导入|
|2|embedding + FAISS 检索|输入问题返回相关原文与页码；保存索引及块映射，重启可加载，资料范围过滤有效|
|3|模型生成与引用|回答方法解释与实验事实问题，证据支持答案，资料不足有明确提示|
|4|FastAPI + Streamlit 网页|走通上传、提问、回答、查看来源，重启资料仍可用，完成 V0.1|
|5|PDF 结构增强、混合检索与现成重排|用真实失败案例检查双栏顺序、表格、方法、数据集与实验设置混淆是否改善|
|6|跨论文比较与计算|核对数据集、划分、指标和实验条件，分别引用可比较输入，用程序计算并展示公式|
|7|论文困难负例重排训练|亲手实现训练循环、保存权重并接回应用，用未参与训练的问题验证|
|8（可选）|文献链与证据精简|有已收录的被引论文时定位原文区域、合并重复证据，关闭后基础问答仍可用|
|9|整理演示成果|保留实际命令、示例问题、改良前后案例与可复核结果|
